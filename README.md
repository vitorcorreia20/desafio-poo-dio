## 🎯 Sobre o Projeto

Este repositório contém a minha solução para o desafio de projeto **"Abstraindo um Bootcamp Usando Orientação a Objetos"** (ou desafio similar) proposto pela plataforma [Digital Innovation One (DIO)](https://www.dio.me/).

O objetivo principal deste projeto foi aplicar na prática os paradigmas da **Programação Orientada a Objetos (POO)** para modelar um domínio de negócios real.

## 🧠 Conceitos Aplicados (Os 4 Pilares da POO)

Durante o desenvolvimento deste desafio, consolidei os seguintes conceitos fundamentais:

* **Abstração:** Capacidade de extrair as características e comportamentos essenciais de entidades do mundo real (ex: `Curso`, `Mentoria`, `Dev`) para dentro do código.
* **Encapsulamento:** Proteção dos dados da aplicação, utilizando modificadores de acesso (`private`, `protected`) e métodos `getters` e `setters`.
* **Herança:** Criação de classes filhas que herdam características de classes mães (ex: `Curso` e `Mentoria` herdando da classe abstrata `Conteudo`), evitando repetição de código.
* **Polimorfismo:** Implementação de comportamentos diferentes para o mesmo método herdado, adaptando-o para cada contexto específico.
